In this repository you will find a collection of fundamental tools to construct numerical methods from scratch in C++.
These files come from programming assignement or personal project in my free time.

The goal is to progressively build a framework dedicated to numerical analysis, starting from basic polynomial algebra and numerical integration and extending to more advanced methods such as the Discontinuous Galerkin (dG) and Hybrid High-Order (HHO) methods. 

Through this project, I aim to explore the connection between mathematical theory, numerical analysis, and practical implementation, while documenting my work as a future graduate student in numerical analysis.
